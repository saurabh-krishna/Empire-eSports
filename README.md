# ⚔️ EMPIRE ESPORTS — Official Website

> *Forged in elite combat rings, disciplined in high-stakes arenas.*

The official website for **Empire Esports**, a new-generation Indian esports organization competing in **BGMI** (Battlegrounds Mobile India). Built with a cyberpunk/tactical aesthetic and a scroll-driven video animation background.

---

## 🌐 Live Site

Deployed on **Vercel** — the root URL routes automatically to the website via `vercel.json` rewrites.

---

## 📁 Project Structure

```
empire esports/
├── esports_org_website/
│   ├── index.html              # Main single-page website
│   ├── logo.png                # Empire Esports logo
│   ├── promo_no_audio.mp4      # Promo video (autoplay, muted)
│   ├── achievement.png         # Achievement graphic
│   ├── 01.jpeg – 05.jpeg       # Player profile photos
│   └── WhatsApp Image *.jpeg   # Tournament achievement screenshots
├── video_frames_30fps/         # 300 JPG frames for scroll animation
│   └── frame_000001.jpg ...
└── vercel.json                 # Vercel routing config
```

## ✨ Features

| Feature | Description |
|---|---|
| 🎬 Scroll Animation | 300-frame canvas animation synced to page scroll position |
| 📺 Promo Video | Full-width autoplay muted promotional video |
| 👥 Roster Section | 5 BGMI player cards with Instagram & YouTube links |
| 🏆 Achievements | Tournament win screenshots gallery |
| 🤝 Partners | Coming soon placeholder |
| 📱 Responsive | Mobile-first layout with Tailwind CSS |
| 🎨 Cyberpunk UI | Tactical dark theme with cyan accents (`#00F5D4`) |

---

## 🧑‍💻 Tech Stack

- **HTML5** — Single-page, no build tools required
- **[Tailwind CSS](https://tailwindcss.com/)** (CDN) — Utility-first styling with custom theme extensions
- **Google Fonts** — *Chakra Petch* & *Rajdhani* for the tactical aesthetic
- **Vanilla JavaScript** — Scroll-driven canvas animation + video autoplay handling
- **Vercel** — Hosting & deployment

## 🚀 Getting Started

No build step needed. Just open `index.html` in your browser:

```bash
# Clone the repo
git clone https://github.com/saurabh-krishna/Empire-eSports.git
cd Empire-eSports

# Open directly in browser
open esports_org_website/index.html
```

### Deploying to Vercel

The `vercel.json` already configures routing. Push to your connected GitHub repo and Vercel handles the rest automatically.
